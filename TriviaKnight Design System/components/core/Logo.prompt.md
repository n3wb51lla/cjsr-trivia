TriviaKnight brand lockup (mark + wordmark). Use in nav bars, footers, and anywhere the brand appears. Temporary placeholder, easy to replace with a final SVG.

```jsx
<Logo href="#top" size="md" />
<Logo onDark size="lg" />
<KnightMark size={40} />
```

`size`: `sm` / `md` / `lg`. Pass `onDark` on navy surfaces. `KnightMark` is the badge glyph alone (favicon, compact spots). Set `wordmark={false}` to show only the mark.
