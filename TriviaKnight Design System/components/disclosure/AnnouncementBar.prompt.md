Dismissible top-of-page bar with the shield mark. Use for the evergreen unlimited-hosting positioning line, not a countdown promo.

```jsx
<AnnouncementBar>
  Built for hosts who believe a subscription should include <b>unlimited trivia nights</b>.
</AnnouncementBar>
```

Wrap emphasis in `<b>` for the gold highlight. Set `dismissible={false}` to make it permanent.
